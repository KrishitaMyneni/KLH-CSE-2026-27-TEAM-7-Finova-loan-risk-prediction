A data-driven system for **loan default prediction and credit risk assessment**. The project integrates and cleans borrower data, evaluates data quality, detects duplicates and noise, and uses machine learning to classify borrowers into low, medium, and high-risk categories.

**Tech Stack:** Python · Pandas · NumPy · Scikit-learn · Machine Learning · Web Dashboard
